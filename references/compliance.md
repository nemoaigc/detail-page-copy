# 合规自检

逐屏检查主标题、副标题、要点。命中就改写，并在该屏下记一行"已改写：原词 → 新词，原因"。
本清单是常见风险的整理，不是法律意见；平台审核和最新法规以官方为准。交付时附一句"合规以平台审核为准"。

## 一、通用禁用（《广告法》第九条等）

| 类型 | 例子 | 怎么改 |
|---|---|---|
| 绝对化（表示排序的"第一原料""第 1 步"不算，照吊牌或包装写的成分含量如"100% 棉"也不算，但机审常误判，建议写"配料表首位""步骤 1"） | 最、第一、顶级、极致、全网最低、国家级、独家、100%、万能、绝无仅有、史无前例 | 改成具体事实："杯壁双层真空"代替"最强保温"；"本店销量靠前"也不行，除非有平台数据并标来源和时间 |
| 虚假或无法证明的承诺 | 永不变形、终身不坏、零风险、无效退款、立竿见影 | 改成带条件的描述："正常使用下""按说明保养" |
| 医疗化用语（非药品、非医疗器械） | 治疗、治愈、消炎、抗菌（无检测报告时）、杀菌、修复受损、预防疾病、减肥、降血压、排毒 | 删除；普通商品写使用感受："清爽不黏""喝着顺口" |
| 贬低或点名竞品 | 秒杀某品牌、比某某好 | 只和"普通款""上一代"比，并写清比的是哪一项 |
| 虚构数据和背书 | 销量 10 万+、好评率 99%、明星同款、央视推荐、获奖 | 无真实依据一律删；有依据要写来源和时间 |
| 制造紧迫 | 仅剩 3 件、最后一天、马上涨价 | 无真实活动数据一律删 |
| 迷信、玄学 | 招财、转运、辟邪、开光 | 删 |
| 国家机关和公职人员 | 国家机关推荐、某部门指定 | 删 |
| 引流 | 加微信、扫码、私信下单、站外链接 | 删 |

## 二、慎用词：有依据才能写，写了要标依据

| 词 | 条件 |
|---|---|
| 进口、原装进口 | 有报关、原产地证明；写清原产国 |
| 有机、绿色 | 有对应认证证书；写证书类型 |
| 专利 | 写专利号和专利类型；申请中的不能写"专利产品" |
| 检测数据（抗菌率、甲醛释放量、保温时长等） | 有检测报告；写检测机构、条件或标准号，例如"按 xx 标准测试" |
| 零添加、无添加、0 糖、无谷物 | 写清不添加的是什么，要和配料表或营养成分表对得上；只有用户原话时可以写在原料或成分屏，不上首屏，配料表进补资料清单；不能暗示同类产品有害 |
| 适用敏感肌、温和、无刺激、低敏 | 要有安全性评估或人体测试（如斑贴试验）依据；只有用户原话时全页都不写，放进补资料清单 |
| 纯天然 | 尽量不用；改写原料来源 |
| 新品、首发 | 写清时间范围 |
