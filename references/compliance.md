# 合规自检

逐屏检查主标题、副标题、要点。命中就改写，并在该屏下记一行"已改写：原词 → 新词，原因"。
本清单是常见风险的整理，不是法律意见；平台审核和最新法规以官方为准。交付时附一句"合规以平台审核为准"。

## 一、通用禁用（《广告法》第九条等）

| 类型 | 例子 | 怎么改 |
|---|---|---|
| 绝对化（表示排序的"第一原料""第 1 步"不算，照吊牌或包装写的成分含量如"100% 棉"也不算，但机审常误判，建议写"配料表首位""步骤 1"） | 最、第一、顶级、极致、全网最低、国家级、独家、100%、万能、绝无仅有、史无前例 | 改成具体事实："杯壁双层真空"代替"最强保温"；"本店销量靠前"也不行，除非有平台数据并标来源和时间 |
| 虚假或无法证明的承诺 | 永不变形、终身不坏、零风险、无效退款、立竿见影 | 改成带条件的描述："正常使用下""按说明保养" |
| 医疗化用语（非药品、非医疗器械） | 治疗、治愈、消炎、抗菌（无检测报告时）、杀菌、修复受损、预防疾病、减肥、降血压、排毒 | 删除；普通商品写使用感受："清爽不黏""喝着顺口" |
| 贬低或点名竞品 | 秒杀某品牌、比某某好 | 只和"普通款""上一代"比，并写清比的是哪一项 |
| 虚构数据和背书 | 销量 10 万+、好评率 99%、明星同款、央视推荐、获奖 | 无真实依据一律删；有依据要写来源和时间 |
| 制造紧迫 | 仅剩 3 件、最后一天、马上涨价 | 无真实活动数据一律删 |
| 迷信、玄学 | 招财、转运、辟邪、开光 | 删 |
| 国家机关和公职人员 | 国家机关推荐、某部门指定 | 删 |
| 引流 | 加微信、扫码、私信下单、站外链接 | 删 |

## 二、慎用词：有依据才能写，写了要标依据

| 词 | 条件 |
|---|---|
| 进口、原装进口 | 有报关、原产地证明；写清原产国 |
| 有机、绿色 | 有对应认证证书；写证书类型 |
| 专利 | 写专利号和专利类型；申请中的不能写"专利产品" |
| 检测数据（抗菌率、甲醛释放量、保温时长等） | 有检测报告；写检测机构、条件或标准号，例如"按 xx 标准测试" |
| 零添加、无添加、0 糖、无谷物 | 写清不添加的是什么，要和配料表或营养成分表对得上；只有用户原话时可以写在原料或成分屏，不上首屏，配料表进补资料清单；不能暗示同类产品有害 |
| 适用敏感肌、温和、无刺激、低敏 | 要有安全性评估或人体测试（如斑贴试验）依据；只有用户原话时全页都不写，放进补资料清单 |
| 纯天然 | 尽量不用；改写原料来源 |
| 新品、首发 | 写清时间范围 |

## 三、类目特殊规定

### 美妆个护
- 化妆品不能宣称医疗作用：治疗、消炎、抗敏（治疗意义）、祛疤、药妆、医学护肤、无副作用。
- 美白、祛斑、防晒、防脱、染发、烫发属于特殊化妆品，要有注册证；资料里没有注册证号就不写这些功效。"提亮肤色""改善暗沉""淡斑"按美白类处理。
- 其他功效（保湿、控油、舒缓、修护、抗皱等）宣称要有功效评价依据；没依据时只写成分名和肤感。"修复受损肌肤""修复屏障损伤"属医疗用语，一律不写。
- "x 天见效""一瓶解决"这类时效和效果承诺不写。
- 必备信息：备案号或注册证号、全成分表（可放参数屏）、适用肤质、使用方法、净含量。

### 食品饮料
- 普通食品不能声称保健功能和疾病预防、治疗作用：降三高、助眠、增强免疫力、排毒养颜。
- 保健食品要有批准文号（"蓝帽子"），并写"本品不能代替药物"；资料里没有批准文号就按普通食品写。
- 必备信息：配料表、净含量、生产日期或保质期说明、贮存条件、生产许可证编号（SC 开头）、产地；有过敏原的要提示。
- "0 糖""低脂"等营养声称要和营养成分表对得上。

### 母婴育儿
- 不能写"治疗湿疹""防止过敏""提高智力""增强免疫"。
- 婴幼儿配方乳粉等声称替代母乳的食品，广告受严格限制；这类商品的详情页只写客观信息（配方、成分表、冲调方式），不写"接近母乳""替代母乳"。
- 婴幼儿纺织品写安全类别时以吊牌标注为准（例如"A 类"），没有标注不写。
- 玩具写适用年龄，小零件要有警示语。

### 宠物用品
- 宠物食品不能宣称预防或治疗疾病，也不写功效承诺：去泪痕、治软便、防猫癣、美毛亮毛、增强免疫。资料里有对应成分时可写"含 xx"，没有就删。可写原料、营养成分分析保证值、适用阶段和体型。
- 必备信息：原料组成、成分分析保证值、适用对象（犬/猫、幼年/成年）、净含量、保质期、喂食量建议；有饲料生产许可证号的写上。
- 驱虫药、宠物药品属于兽药，本技能只写客观信息，不写疗效。

### 数码家电
- 能效等级、3C 认证要和铭牌或证书一致；没有就不写。
- 续航、充电速度、降噪深度等数字要写测试条件。
- 不写"军工级""医用级""航天材料"，除非有对应证明。

### 家居家装
- 环保等级（如甲醛释放等级）要和检测报告或标签一致，写标准号；没有报告不写"零甲醛""无甲醛"。
- 承重、尺寸写实测值和测量方式；家具写安装方式。

### 服饰鞋包
- 面料成分以吊牌为准，写百分比；"真皮""羊绒""进口面料""纯手工"等要有依据。
- 不写"大牌同款""某品牌平替"。
- 不写"显瘦 10 斤""增高 8cm"这种无法证明的效果，改为"高腰设计""内增高 x cm（以实测为准）"。
