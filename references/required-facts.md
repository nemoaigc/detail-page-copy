# 必须问到的确定信息

这些信息要原样印在详情页上，写错会导致退货、投诉或违规。**只能由商家给，不能推理、不能按同类商品估、不能从图片外观猜**（图上清晰可读的文字除外）。

事实卡整理完后，对照下面两张表：表里有、事实卡里没有、而且适用于这款商品的，就是收集表里要商家填的项。规则见 SKILL.md 第 2 步，表的样子见文末「收集表模板」。

## 所有类目都要问

标「参数」的是必填：缺了一定要问，用户说"直接写"也要问。其余是选填。

| 项 | 类型 | 为什么不能推理 | 怎么问 |
|---|---|---|---|
| 商品归属 | 选填 | 决定能不能写"官方""原厂""品牌直营"，能不能用品牌故事屏 | 这款是你自己的品牌、代理或经销别人的品牌（有没有授权），还是没有品牌的工厂货？ |
| 品名和型号 | 参数 | 要和包装、吊牌、备案一致 | 包装或吊牌上的品名、型号是什么？ |
| 规格 | 参数 | 容量、重量、数量、尺寸写错直接退货 | 规格是多少？（容量 / 净含量 / 尺寸 / 件数，带单位） |
| 款式和选项 | 参数 | 颜色、版本、套餐之间有什么差别只有商家知道 | 一共卖几个颜色或版本？各自差别是什么？ |
| 材质或成分 | 参数 | 涉及安全和虚假宣传 | 主要材质或成分是什么？以包装、标签为准 |
| 包装里有什么 | 选填 | 少写一件就是投诉 | 一份里包含哪些东西、各几个？ |
| 证书和报告 | 选填 | 没有就不能写检测、认证、专利 | 有哪些检测报告、认证、备案号、专利？没有就说没有 |
| 售后政策 | 选填 | 不能替商家承诺 | 退换、保修是怎么定的？没定就不写 |

## 各类目另外要问

带【参数】的是必填。

| 类目 | 要问的项 |
|---|---|
| 数码家电 | 【参数】额定功率和电压；【参数】接口、兼容的设备或系统；【参数】电池容量和续航的测试条件；【参数】尺寸和重量；3C 证书编号；保修期和保修范围 |
| 服饰鞋包 | 【参数】尺码表（每个尺码的具体尺寸，量法）；【参数】面料成分和含量（以水洗标为准）；【参数】箱包的外尺寸、容量、自重；身高体重对应的尺码推荐、是否偏码；模特身高体重和所穿尺码；洗涤方式；吊牌上的执行标准和安全类别；面料克重（要写进标题或卖点时） |
| 美妆个护 | 【参数】净含量；【参数】全成分表（以包装为准）；【参数】保质期和开封后使用期限；【参数】适用肤质和不适用的情况（以包装或说明书为准）；备案或注册编号；使用方法和用量 |
| 家居家装 | 【参数】外形尺寸（长宽高，折叠款要展开和收起两组）；【参数】承重或容量；【参数】要不要安装、安装要什么工具；执行标准号；清洁和保养方式 |
| 食品饮料 | 【参数】配料表；【参数】营养成分表；【参数】净含量和每份规格；【参数】保质期和储存方式；【参数】产地；生产许可证号；过敏原提示 |
| 母婴育儿 | 【参数】适用年龄或体重段；【参数】尺码表；【参数】材质；【参数】保质期；"不添加"清单（只认包装或报告上写了的）；执行标准号和检测报告；使用方法 |
| 宠物用品 | 【参数】适用的宠物种类、年龄段、体型；【参数】原料组成；【参数】成分分析保证值；【参数】净含量；【参数】保质期和储存方式；喂食量表；登记证号或执行标准号（有的话） |

## 收集表模板

下面是一款保温杯（家居家装）的例子。已知的预填，缺的留空；不适用的项（安装工具）没有列。

> 这些信息会原样印在详情页上，所以需要你来填。没有的写"没有"；暂时不清楚的写"先空着"，我会在页面上留位置。左边"已知内容"是我从你给的资料里读到的，请顺手核对。

| 项 | 必填 | 已知内容 | 请填写 | 填法示例 |
|---|---|---|---|---|
| 品名和型号 | 是 | 316 不锈钢弹盖吸管保温杯（来自你的描述） | | 包装上的品名、型号 |
| 容量 | 是 | 600ml（来自你发的参数） | | |
| 外形尺寸 | 是 | | | 高 23cm，杯口直径 7cm |
| 重量 | 是 | | | 空杯 320g |
| 颜色或版本 | 是 | | | 3 个颜色：白、粉、墨绿；功能一样 |
| 材质 | 是 | 内胆 316 不锈钢（图上文字） | 杯盖、吸管、密封圈的材质： | 杯盖 PP，吸管和密封圈食品级硅胶 |
| 商品归属 | | | | 自己的品牌 / 代理（有授权）/ 代理（无授权）/ 无品牌工厂货 |
| 执行标准号 | | | | GB/T 29606-2013 |
| 保温保冷时长和检测报告 | | | | 有报告：保冷 12 小时（附报告）/ 没有 |
| 包装里有什么 | | | | 杯子 1、吸管 2、吸管刷 1、说明书 1 |
| 清洁方式 | | | | 能否进洗碗机；配件能否拆洗 |
| 退换和保修 | | | | 7 天无理由；杯盖一年内坏了免费换 / 没定 |

一个链接多款时，用户没分款给的信息照常预填，「请填写」里加一句"各款是否都适用，不同请分别写"；款与款的差别（如加绒款的里料）单独一行问。

## 不用问的

- 用户已经给过的；图上文字清晰可读、已经记进事实卡的。
- 明显不适用于这款商品的（杯子不问"安装工具"）。
- 文案自己能决定的：标题怎么写、卖点怎么排、画面怎么拍、语气风格。
- 价格、促销、销量：用户没提就不写，也不问。
