# 平台差异

只列影响文案写法的部分。具体图片尺寸以平台后台当前要求为准。

| 平台 | 详情页形态 | 文案上要注意 |
|---|---|---|
| 淘宝 / 天猫 | 竖版长图，手机端为主，常见宽度 750 或 790px | 首屏决定是否继续往下看；文字占画面三成以内；不能放二维码、联系方式、站外链接 |
| 京东 | 竖版长图，手机端为主 | 参数和售后信息看得多，参数屏要完整；自营和 POP 店的售后说法不同，以店铺政策为准 |
| 拼多多 | 竖版长图 | 买家对价格敏感，但"全网最低""比某某便宜"仍然不能写；多写实拍、细节和用量 |
| 抖音电商 | 竖版长图，多数买家从短视频或直播进入 | 买家已经看过视频，首屏直接给结论；对"限时""仅剩"的审核更严，没有真实活动不写 |

多平台同时投放时，通用稿取各平台要求的并集（任何一个平台不让写的都不写），再单列各平台的首屏版本。
