# 家居家装

适用：收纳、厨具餐具、清洁用品、家纺床品、家具、灯具、装修建材。

## 买家常问
1. 尺寸多大？放得下吗？（冰箱、柜子、床宽）
2. 什么材质？安全吗？有没有味道？能不能接触食物？
3. 结实吗？能承重多少？耐高温吗？
4. 好不好清洗、打理？
5. 要不要安装？好不好装？
6. 用了以后能有什么变化？（整洁、省空间、好睡）
7. 家纺：会不会起球、掉色、缩水？

## 必备屏
- 材质与安全屏：材质名（食品级 PP、长绒棉等）+ 检测报告要点（有资料时）
- 尺寸规格屏：每个型号的长宽高或容量；用常见物品作参照（可乐罐、A4 纸、手机），或按使用对象对照（桌布对几人桌、床品对床宽）；可折叠的给使用时和收纳时两组尺寸
- 参数屏：品名、材质、耐温范围、承重、尺寸、安装方式

## 可选屏
- 使用前 / 使用后对比屏：收纳、清洁类有对比素材时用；天猫 6 个品牌店样本都没有这屏，不算必备。

## 推荐屏序
- 功能型（收纳、厨具、清洁）：场景首屏 → 卖点总览 → 材质安全 → 结构细节 → 使用前后对比 → 单卖点逐屏 → 参数 → 尺寸
- 氛围型（家纺、家居装饰）：氛围首屏 → 氛围 1–2 屏 → 面料 → 面料对比 → 工艺细节（逐个讲，统一句式）→ 洗涤保养 → 尺寸表

## 写法要点
- 功能型每屏"功能名 + 利益句"："双扣带胶圈 / 汤汁倒放不洒"。
- 尺寸一定配参照物，买家对数字没感觉。
- 卖点总览可以只用三个短词配图标（如"透气储物 / 耐磨耐用 / 简约设计"），每个词要在事实卡里有依据。
- 氛围型可以用情绪短句做首屏，但面料和工艺屏要回到事实（支数、工艺名）。
- 家纺把退换说明（如"洗后不退"）放在显眼位置，资料里有才写。

## 证据
材质证明、检测报告（写标准号）、使用前后实拍、尺寸实测、承重实测。

## 本类目的坑
- 没有检测报告不写"零甲醛""无甲醛""无毒"。
- "保鲜提升 20%"这类数字要写测试条件和来源，否则删。
- 和"其他家面料"比时不点名品牌，写"普通 40 支面料"这种具体对象。

## 采样依据
1688 两个商品：卡扣保鲜收纳盒（19 屏）、长绒棉四件套（14 屏），分别代表功能型和氛围型。

天猫 6 个品牌旗舰店商品（宜家盘子架、无印良品晾晒架、Zara Home 餐盘、收纳篮、车载香薰、桌布）：文字很少，靠场景图和白底图；都给了尺寸和材质名，都没有检测报告和对比屏。品牌店靠品牌背书才能这么写，普通商家仍按上面的屏序回答买家问题。
