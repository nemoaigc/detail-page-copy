# 数码家电

适用：手机配件、耳机音箱、个护小家电（吹风机、剃须刀）、厨房小家电、清洁电器、大家电。

## 买家常问（没有店铺真实提问时用）
1. 这东西性能到底怎么样？（续航、功率、转速、容量）
2. 和普通款 / 上一代比强在哪？
3. 适不适合我的场景？（宿舍、车内、户外、小户型）
4. 好不好操作？有几个档位？
5. 吵不吵、重不重、占不占地方？
6. 兼容吗？（接口、蓝牙版本、电压、适配机型）
7. 坏了怎么办？保修多久？

## 必备屏
- 首屏：品类名 + 2–3 个带数字的卖点标签
- 卖点总览（图标宫格，4–9 个）
- 至少一屏对比（本品 vs 普通款 / 新版 vs 旧版，写清比的是哪一项）
- 参数表（型号、尺寸、重量、功率/电池、接口、版本、包装清单、保修期；有认证和能效写认证和能效；缺的项写待商家补充）

可选：
- 售后屏：有店铺政策原文时加，写保修期限和范围；没有原文时保修期只进参数表。

## 推荐屏序
首屏 → 卖点总览 → 痛点或场景 → 单卖点逐屏（一屏一个，带数字）→ 对比 → 操作/按键说明 → 细节 → 参数表（含包装清单和保修期）→ 售后（可选）

## 写法要点
- 每个卖点尽量配一个数字，数字带条件："续航 9 小时（音乐播放，50% 音量）"。没有条件的数字放进待补充，问清测试条件。
- 标题句式："卖点名 + 结果"，两行。例："升级大风力 / 中长发 3 分钟吹干"。
- 技术词要翻译成买家能感知的结果：说"不烫头皮"，再在副标题写"NTC 温控"。
- 操作说明屏用"按一下 / 长按 2 秒"这种动作描述。

## 证据
性能数字、结构或爆炸图、芯片和型号、对比表、认证证书（3C、能效）。

## 本类目的坑
- 续航、降噪深度、充电速度要写测试条件。
- "军工级""医用级""航天材料"没有证明不写。
- 能效等级、3C 认证必须和铭牌或证书一致，没有就不写。
