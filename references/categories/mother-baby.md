# 母婴育儿

适用：纸尿裤、湿巾、洗护、喂养用品、婴童服饰、玩具、孕产用品、出行和大件用品（推车、安全座椅、餐椅）。婴幼儿配方奶粉的限制见「本类目的坑」。

## 买家常问
1. 安全吗？有没有添加香精、酒精、荧光剂？
2. 宝宝皮肤敏感能用吗？
3. 尺码怎么选？（按体重 / 月龄）
4. 会不会红屁屁、侧漏、勒腰？（纸尿裤）
5. 材质是什么？有没有检测报告？
6. 保质期多久？开封后多久用完？
7. 怎么用？（喂养、冲调、清洗方式）

## 必备屏
- 安全承诺屏（首屏或第 2 屏）："不添加 xx"清单——只列资料里明确写了的
- 尺码屏：按体重（kg）或月龄
- 检测屏：检测项目 + 标准号（如资料里写了 GB 号）
- 参数屏：品名、规格、主要成分、保质期、适用年龄
- 使用说明屏：要安装、冲调、清洗或消毒的商品必备（奶瓶、吸奶器、推车、安全座椅、餐椅等），按步骤写，步骤以说明书为准

可选：
- 对比屏：本品和普通款、旧款或国标要求比，有对比资料时加。

## 推荐屏序
首屏（品类 + 安全承诺）→ 卖点编号逐条（01#、02#…，每条落在宝宝身上）→ 对比（可选）→ 实测（有资料时）→ 检测与资质 → 细节 → 尺码 → 参数 → 使用说明

## 写法要点
- 利益落在宝宝身上："擦嘴巴也放心""一晚不侧漏"，副标题写依据。
- 语气是"放心、安心"，少用情绪渲染。
- 实测屏写清测法："荧光笔照射测试（店内实拍）"。
- 按体重给尺码时附一句"在两个尺码之间时建议选大一码"，前提是资料里有这个建议。

## 证据
检测报告（标准号、检测机构）、成分表、卫生许可证（消毒产品类）、婴幼儿纺织品安全类别（吊牌标注）、原料供应商（有资料时）。

## 本类目的坑
- 不写"治疗湿疹""防过敏""提高智力""增强免疫力"。
- 婴幼儿配方乳粉只写客观信息（配方、成分表、冲调方式），不写"接近母乳""替代母乳"。
- "无菌""杀菌"需对应许可和检测，没有不写。
- 纺织品的安全类别以吊牌标注为准，没有标注不写。
- 玩具写适用年龄，有小零件的要有警示语。
