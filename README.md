# 商品详情页文案（detail-page-copy）

一个写国内电商商品详情页逐屏文案的技能。只写文案，不出图。

## 它做什么

- 按类目套用详情页结构：数码家电、服饰鞋包、美妆个护、家居家装、食品饮料、母婴育儿、宠物用品。
- 用买家提问决定讲哪些卖点、先讲哪个。
- 可以照用户给的同类爆款详情页截图拆出屏结构来排屏。只借结构，不用它的文案、数字、品牌和图片。
- 每条卖点标依据；没有依据的数字不出现。
- 按广告法清单自检，记录改了什么。
- 交付：买家问题表、事实卡、逐屏文案稿、补资料清单、合规改写记录、图上文字清单。

## 目录

```
SKILL.md                      流程和规则
references/categories/*.md    7 个类目的买家常问、必备屏、推荐屏序
references/compliance.md      禁用词、慎用词和类目特殊规定
references/platforms.md       淘宝天猫、京东、拼多多、抖音的文案差异
references/output-format.md   交付格式和样例
scripts/slice_long_image.py   把详情页长截图切段（需要 Pillow）
```

## 安装

把整个目录放进所用工具的技能目录，例如 Claude Code 的 `~/.claude/skills/detail-page-copy/`。

## 说明

- 当前版本 0.3.1，只用模拟商品试跑过，没有用真实店铺数据验证。
- 类目结构主要依据 1688 商品详情页采样，样本每类 2–3 个。
- 合规清单是整理，不是法律意见；以平台审核为准。
- 技能不抓取电商页面。参考页面请用户提供截图。
